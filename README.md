# Advent of Code 2026

Simple Python boilerplate for solving a two-part coding challenge.

1. Save the challenge input as `input.txt` in the repository root.
2. Implement `part1` and `part2` in `main.py`. Each function receives the full input as a string.
3. Run the solution with:

   ```sh
   python main.py
   ```

The starter functions return `None` until implemented. Copy `main.py` and `input.txt` into a separate directory for each challenge to keep solutions and inputs independent.
